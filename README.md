# 授業サイトナビ

全教科・自立活動・SSTで使えるサイトを、教科から探してすぐ開ける無料Webアプリです。

公開ページ：https://uramotokou-hash.github.io/jugyo-site-navi/

## できること

- 教科・種類・対象学年・キーワードで探す
- ★お気に入り、子どもに見せる画面（★のサイトを大きく表示＋QRコード）
- QRコードつき配布プリント（A4）
- サイトのトップ画面のサムネイル表示（自動取得、または自分のスクショを登録）
- 自分のサイトの追加・メモの編集・非表示
- データのコピー・読みこみ（別の端末へ移す）

## データの保存

入力した内容は、使っている端末のブラウザ（localStorage）だけに保存されます。外部には送信しません。
ただし、サムネイルの自動表示をオンにしているときは、表示するサイトのURLを画面写真サービス（WordPress.com mShots）に送ります。

## 掲載サイトの更新

掲載サイトは `index.html` の `PRESET` 配列にあります。
`ok:false` のサイトは「URL要確認」と表示されます。

掲載情報の確認日：2026年11月5日〜9日
